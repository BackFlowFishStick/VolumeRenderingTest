# 3D Slicer 5.10.0 体渲染预设

从本机正在运行的 3D Slicer 5.10.0 的 Volume Rendering 预设场景读取，共 31 个预设。已切换桌面模块到 Volume Rendering，没有替换当前体渲染属性。

- `presets-all.json`：便于网页读取的汇总，包含标量分量 0 的颜色、灰度不透明度、梯度不透明度控制点，以及插值和光照参数。
- 每个以预设名称命名的 `.vp.json`：由 Slicer 原生存储节点输出的体属性文件，可用于 Slicer 重新读取。
- `current-volume-property.vp.json`：当前胸部影像正在使用的体属性快照，节点名为 CT-Coronary-Arteries；它可能已被用户调整，不能仅凭名称判断与内置预设完全一致。

颜色点格式：`[灰度, R, G, B, midpoint, sharpness]`。
透明度点格式：`[灰度或梯度, opacity, midpoint, sharpness]`。
颜色和不透明度通常在 0–1；标量灰度的物理含义取决于输入影像，当前 CT 已转换为 HU。

## 在 Slicer 中调取

```python
logic = slicer.modules.volumerendering.logic()
preset = logic.GetPresetByName('CT-Lung')
property = preset.GetVolumeProperty()
color = property.GetRGBTransferFunction(0)
opacity = property.GetScalarOpacity(0)
gradient = property.GetGradientOpacity(0)
```

这批文件是渲染参数，不是器官模型或新影像，也不执行自动分割。接入 Three.js 时需要体数据纹理与体光线投射渲染器，将传递函数用于沿射线采样的灰度值；不能直接作为 STL 材质使用。须处理 opacity unit distance、梯度、插值方式和采样步长，才能接近 Slicer 的显示。MIP 等投射模式属于渲染显示/视图设置，不能只靠体属性预设决定。
