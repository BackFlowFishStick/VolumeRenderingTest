# 03 - 核心功能详解

## 1. 三种渲染模式

定义于 `Runtime/VolumeObject/RenderMode.cs`：

| 枚举值（代码中的拼写） | 说明 |
| --- | --- |
| `DirectVolumeRendering` | 直接体渲染（DVR）：光线步进采样，用 1D/2D 传输函数映射颜色与不透明度并累加 |
| `MaximumIntensityProjectipon` | 最大强度投影（MIP）：整条射线上取最大密度值显示（注意枚举名拼写为 Projectipon，为仓库原样） |
| `IsosurfaceRendering` | 等值面渲染：光线行进，命中密度处于“可见值域”且梯度大于阈值的第一个点即着色停止 |

切换渲染模式通过 `VolumeRenderedObject.SetRenderModeAsync(...)` 完成，底层切换着色器关键字
`MODE_DVR` / `MODE_MIP` / `MODE_SURF`。

## 2. 传输函数（Transfer Function）

传输函数把**密度值**（2D 版本再加**梯度幅值**）映射为颜色和不透明度，用于突出不同组织
（皮肤、骨骼、器官等）。

- **1D 传输函数**（`TransferFunction`）：X 轴=密度，Y 轴=不透明度。
  - 灰色 alpha 控制点构成不透明度曲线，右键添加控制点。
  - 底部渐变色条映射颜色，右键添加颜色控制点。
  - 纹理宽度 1024，线性插值 + SmoothStep 平滑，输出 `_TFTex`。
- **2D 传输函数**（`TransferFunction2D`）：X 轴=密度，Y 轴=梯度幅值。
  - 矩形区域控制形状，支持最小/最大 alpha、颜色选择。（文档标注仍为 WIP）
- 每个 `VolumeRenderedObject` 同时持有 1D 与 2D 传输函数，通过 `TFRenderMode`（TF1D/TF2D）切换。
- 传输函数作为 `ScriptableObject` 可序列化保存，编辑器内有专用编辑窗口。

## 3. 光照与阴影

- **光照**：`VolumeRenderedObject` 支持开启光照。系统为数据集生成**梯度纹理**（gradient texture），
  以梯度方向作为法线，在着色器中执行 Phong 光照（漫反射 + 环境光 + 镜面反射）。
  - 梯度类型可选：`CentralDifference` / `SmoothedCentralDifference` / `Sobel` / `SmoothedSobel`
    （`GradientType`，默认 CentralDifference，可通过 `PlayerPrefs("DefaultGradientType")` 配置）。
  - 光源可选：`SceneMainLight`（场景主平行光）或 `ActiveCamera`（摄像机方向）。
  - 梯度光照阈值（min/max）控制低梯度区域的受光程度。
- **阴影体（Shadow Volume）**：`ShadowVolumeManager` 组件，需要 Compute Shader 支持。
  - 用 `Runtime/Resources/ShadowVolume.compute` 从光源方向对体数据投射光线，生成 3D 阴影纹理 `_ShadowVolume`。
  - 由于计算耗时，阴影体被切成 5×5×5 块，**每帧只更新一块**，代价较高但效果更好。

## 4. 采样与优化

| 特性 | 说明 |
| --- | --- |
| 三线性/三三次插值 | 开启 `cubicInterpolationEnabled` 后在着色器用 `TricubicSampling.cginc` 做三三次插值，消除“阶梯伪影”，代价高 |
| 噪声抖动 | `_NoiseTex` 在光线起点加随机偏移，消除 banding 伪影 |
| 早期光线终止 | `RAY_TERMINATE_ON`：累计不透明度超过阈值即终止，大幅提速 |
| 采样率倍率 | `_SamplingRateMultiplier`（0.2~2.0）控制每条光线采样步数，兼顾质量与性能 |
| 可见值域 | `visibilityWindow`（min/max 密度窗口）滤除窗口外的体素 |

## 5. 切面与裁剪工具（Cross Section / Cutout）

通过 `CrossSectionManager`（每个体对象最多 8 个切面）统一管理，向材质写入矩阵数组
`_CrossSectionMatrices`、类型数组 `_CrossSectionTypes` 并启用 `CROSS_SECTION_ON`。

- **切面平面（CrossSectionPlane）**：任意移动/旋转的平面，裁剪平面一侧的数据。
- **盒式裁剪（CutoutBox）**：两种模式
  - Exclusive：挖掉与盒子重叠的部分；
  - Inclusive：只保留盒子内部（挖掉外部）。
- **球式裁剪（CutoutSphere）**：同盒式，inclusive/exclusive 两种模式。
- 裁剪计算在着色器 `VolumeCutout.cginc` 中完成（`IsCutout()`）。

## 6. 切片渲染器（Slice Renderer）

`SliceRenderingEditorWindow` 提供轴对齐（或自由）切片视图：

- 创建 X/Y/Z 方向切片平面；
- 交互模式：**移动切片**、**检查数值**（左下角打印密度值）、**测量距离**（两点直线距离）；
- 顶部按钮支持 90° 旋转切片视图。

运行时对应 `SlicingPlane` 组件与 `EditSliceGUI`（IMGUI 切片编辑）。

## 7. 分割（Segmentation）与 PET/叠加体

- **分割标签**：`SegmentationBuilder` 根据数据中的整数值自动识别分割 ID，并映射到
  TotalSegmentator（CT）或 TotalSegmentatorMR（MR）的解剖学标签（肝脏、骨骼、器官等）。
  自动为每个标签分配颜色（含标准颜色表）。
- **渲染模式**（`SegmentationRenderMode`）：`OverlayColour`（叠加颜色）或 `Isolate`（只显示分割区域）。
- **叠加体/多体**：`VolumeRenderedObject` 可设置 `secondaryDataset` 与 `secondaryTransferFunction`，
  着色器变体 `SECONDARY_VOLUME_ON` + `MULTIVOLUME_OVERLAY`（叠加）/ `MULTIVOLUME_ISOLATE`（隔离），
  常用于 **PET 叠加到 CT**。
- `OverlayType`：`None` / `Overlay` / `Segmentation`。

## 8. 深度写入与多数据集相交

- 着色器变体 `DEPTHWRITE_ON` / `DEPTHWRITE_OFF` 控制是否写深度。
- 开启深度写入后，多个体数据集（或与普通网格/盒子/球体）可正确相交遮挡。
- 关闭可提升 VR 性能，但失去深度相交能力。

## 9. 其他

- **坐标系统与真实尺寸**：DICOM/NRRD 会做坐标系统转换，使用米制单位；默认导入后自动归一化缩放，
  需要保持真实尺寸可把外层 GameObject 的 scale 设为 (1,1,1)。
- **降采样提示**：编辑器导入过大数据集时提示是否降采样（`Show downscale prompt` 设置）。
- **WebGL**：可使用但内存受限，需启用 `ALLOW_MEMORY_GROWTH`；由于无法访问本地文件系统，
  需在编辑器导入后保存场景，或用 `UnityWebRequest` 下载。
