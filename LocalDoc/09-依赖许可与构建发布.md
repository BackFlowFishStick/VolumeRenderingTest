## 3. 构建与 CI

`scripts/` 目录：

| 脚本 | 说明 |
| --- | --- |
| `ExportUnityPackage.py` | 用 Unity 批处理导出 `.unitypackage`（`-assetstore` 参数用于 Asset Store 版） |
| `DocsToPDF.py` | 把 Markdown 文档转换为 PDF（MANUAL.pdf，需要 pandoc + TeX） |
| `ci/activate-license.sh` | CI 中激活 Unity 许可证 |

`.github/workflows/` 三个工作流：

1. **Package**（push/PR 触发）：Unity 2022.3.22f1 容器中导出 `UnityVolumeRendering.unitypackage`。
2. **Package for Release**（release/workflow_dispatch）：分别用 2022.3.22f1 与 6000.0.23f1 导出包。
3. **Package for Unity Asset Store**：额外生成 `EasyVolumeRenderer.unitypackage`（带 pandoc/texlive 生成文档）。
