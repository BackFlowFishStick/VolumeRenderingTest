# 04 - 渲染模式详解

> 枚举：`Runtime/VolumeObject/RenderMode.cs`；
> 着色器实现：`VolumeRendering.hlsl` 的 `volrend_dvr` / `volrend_mip` / `volrend_surf`。

本项目一套光线步进框架支持三种渲染模式，由着色器关键字
`MODE_DVR` / `MODE_MIP` / `MODE_SURF` 切换。

| 枚举（注意源码拼写） | 含义 | 关键字 |
|---|---|---|
| `DirectVolumeRendering` | 直接体渲染 | `MODE_DVR` |
| `MaximumIntensityProjectipon`（源码拼写即此） | 最大强度投影 | `MODE_MIP` |
| `IsosurfaceRendering` | 等值面渲染 | `MODE_SURF` |

> 小知识：`MaximumIntensityProjection` 在源码里被拼成了 `Projectipon`，这是仓库原样，
> 引用时要按源码拼写来写。

## 1. DVR — 直接体渲染（默认）

### 原理

沿射线把每个采样点的密度经传输函数变成 RGBA，然后**前→后 Alpha 合成**。
可以把它想成「往透明胶卷上层层叠色」。

### 特点

- 最能体现「半透明、内部结构可见」；
- 结果由**传输函数决定**：同一个数据不同 TF 完全不同；
- 计算量最大（要采样+合成一整条线）；
- 支持光照、阴影、切面、分割叠加等全部增强。

### 关键点

- 只渲染 `[MinVal, MaxVal]` 窗口内的密度（`visibilityWindow`）；
- 提前终止 + 不透明度校正（见 02 章）；
- 视觉质量与采样率强相关。

## 2. MIP — 最大强度投影（Maximum Intensity Projection）

### 原理

沿整条射线找**密度最大值**，把「最大密度」作为该像素的输出。
就像 X 光/血管造影——只显示最亮/最密的结构。

### 实现（volrend_mip）

```hlsl
float maxDensity = 0;
for (每一步) {
    density = getDensity(currPos);
    if (density > maxDensity && 在可见窗口内) {
        maxDensity = density;  // 记录最大密度及位置
    }
}
output.colour = float4(1,1,1, maxDensity); // 白×最大强度
```

### 特点

- 只输出最大密度对应的强度，**不读传输函数颜色**（所以改 TF 对 MIP 无效）；
- 常用于**血管、骨骼、造影剂增强**场景（高密度结构突出）；
- 速度与 DVR 相当，但没有半透明合成，看起来是「实心投影」。

## 3. 等值面渲染（Isosurface）

### 原理

沿射线找到**第一个「密度落在窗口内、且梯度幅值足够大（在等值面上）」的点**，
把该点的梯度当法线做光照，输出**不透明表面颜色**，然后立刻停止。

### 实现（volrend_surf）

```hlsl
for (每一步) {
    density = getDensity(currPos);
    if (density > _MinVal && density < _MaxVal) {
        gradient = getGradient(currPos);
        gradMag = length(gradient);
        if (gradMag > _MinGradient) {          // 确实是「面」
            normal = gradient / gradMag;        // 梯度方向 = 法线
            col = getTF1DColour(density);       // 表面颜色
            col.rgb = calculateLighting(col.rgb, normal, ...);
            col.a = 1.0;                        // 不透明
            break;
        }
    }
}
```

### 特点

- 输出**单一不透明表面**（像普通 3D 模型），内部不可见；
- `_MinGradient` 是「梯度可见阈值」：只有密度变化剧烈的点才算表面，
  用来跳过均匀区域的噪点；
- 类似「等值面提取」，但**不预先建网格**，是运行时求交；
- 常用于把某个密度层（例如骨骼表面）单独展示出来。

## 4. 三种模式对比总结

| 维度 | DVR | MIP | Isosurface |
|---|---|---|---|
| 输出 | 半透明合成色 | 最大强度 | 不透明表面 |
| 是否读传输函数颜色 | ✅ | ❌（只读强度） | ✅（表面颜色） |
| 是否读传输函数透明度 | ✅ | ❌ | 不读（强制 alpha=1） |
| 内部结构 | 可见 | 被高密度遮挡 | 不可见 |
| 典型用途 | 整体看组织 | 血管/骨骼/增强 | 单层表面 |
| 是否需梯度 | 光照/2D TF 时才需 | 否 | ✅ 必需 |
| 默认采样步数上限 | 512 | 512 | 1024 |

## 5. 如何切换（C# API）

```csharp
// 异步推荐（大纹理切换避免卡顿）
await volObj.SetRenderModeAsync(RenderMode.DirectVolumeRendering);
// 同步
volObj.SetRenderMode(RenderMode.MaximumIntensityProjectipon);
volObj.SetRenderMode(RenderMode.IsosurfaceRendering);
```

> 提示：切到 MIP/等值面后，教学版 TF（全透明）不会生效——
> MIP 不看 TF 颜色、等值面强制 alpha=1，这是 `ApplyHounsfieldTransferFunction`
> 强制切回 DVR 的原因（见示例工程代码注释）。
