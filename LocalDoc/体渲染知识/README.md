# 体渲染知识（Knowledge of Volume Rendering）

> 本文档系列面向「想真正理解本项目体渲染原理」的读者，回答的问题是：
> **当前项目使用的是哪种体渲染方式？要读懂/使用/修改它，我需要掌握哪些知识？**
>
> 仓库：`C:\UnityProjs\TestVolumeRendering`（基于 `UnityVolumeRendering` / Easy Volume Renderer v1.8.0）
> 示例工程：`VolumeRenderingSample`（Unity 6 + URP）、`VolumeRendering_2022`（Unity 2022.3）

## 一句话总结本项目用的体渲染方式

**GPU 光线步进（Ray Marching）+ 直接体渲染（Direct Volume Rendering, DVR）**，
在**片元着色器（Fragment Shader）**中逐像素对单位立方体做光线与包围盒求交，
沿视线方向对 3D 纹理等距采样，用**传输函数（Transfer Function）**把采样到的
**密度值（density）**映射成颜色与不透明度，再按**从前到后（front-to-back）**
做 **Alpha 合成（alpha compositing）**，最终得到体数据的三维透视影像。

除 DVR 外，同一套步进框架还支持 **MIP（最大强度投影）** 与 **等值面（Isosurface）** 两种变体。

## 知识前提（Recommended Prerequisites）

1. **三维坐标与向量**：物体空间 / 世界空间 / 相机空间；点乘（dot）在光照中的含义。
2. **Unity Shader 基础**：`vert`/`frag`、`Texture3D`、`SV_TARGET`、`multi_compile` 关键字。
3. **图像合成基础**：RGBA 颜色与 Alpha 混合，`Blend SrcAlpha OneMinusSrcAlpha` 的含义。
4. **医学影像常识（非必须）**：DICOM、CT 的 Hounsfield 单位（HU）、灰度密度。
