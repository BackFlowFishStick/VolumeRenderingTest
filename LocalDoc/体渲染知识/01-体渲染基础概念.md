# 01 - 体渲染基础概念

## 1. 什么是体数据（Volume Data）

体数据描述的是**三维空间中的一个标量场**：在规则网格的每个格子（**体素 Voxel**）上
存放一个数值，这个数值通常叫 **密度值（density）** 或**强度值（intensity）**。

本项目把体数据抽象为 `VolumeDataset`（`Runtime/VolumeData/VolumeDataset.cs`）：

```csharp
public float[] data;      // 展平后的一维数组，下标 = x + y*dimX + z*(dimX*dimY)
public int dimX, dimY, dimZ; // 三个方向上的分辨率
public Vector3 scale;      // 各向异性缩放（真实尺寸，如 DICOM 像素间距）
public Quaternion rotation;
```

### 医学场景中的密度含义

| 数据类型 | 密度值含义 | 典型范围 |
|---|---|---|
| CT（DICOM） | Hounsfield 单位（HU）：空气≈-1000，水≈0，软组织≈40，骨≈+1000+ | -1000 ~ +3000 |
| MR | 相对信号强度（无绝对单位） | 0 ~ 4095（16bit）等 |
| 科学数据（NRRD/NIFTI/VASP） | 任意物理量 | 不定 |

> 本项目示例 `VolumeRenderingSample` 的 `ApplyHounsfieldTransferFunction` 正是按
> HU 值（-1000~3000）构造传输函数控制点来区分空气/软组织/骨骼的。

## 2. 体渲染 vs 面渲染（Mesh Rendering）

| 维度 | 面渲染（多边形） | 体渲染 |
|---|---|---|
| 数据形态 | 顶点+三角面 | 三维标量场（体素） |
| 表现对象 | 表面（皮肤、骨骼轮廓） | 内部结构也可透明可见 |
| 是否要提取几何 | 需要（分割/等值面提取） | 不需要，直接对体素采样 |
| 半透明 | 难 | 天然支持（每层密度一个 alpha） |
| 代表性算法 | 光栅化、Marching Cubes | 光线步进、切片合成等 |

体渲染特别适合**医学影像、科学仿真场**这类「内部也有信息、且需要半透明透视」的场景。

## 3. 本项目的整体流水线

```
体数据集 (DICOM/NRRD/NIFTI/VASP/RAW/图像序列)
   │  ImporterFactory + 各 Importer
   ▼
VolumeDataset (float[] + dims + scale)
   │  VolumeDataset.GetDataTextureAsync()  →  Texture3D(_DataTex, RHalf)
   │  VolumeDataset.GetGradientTextureAsync() → Texture3D(_GradientTex, RGBAHalf)
   ▼
VolumeObjectFactory.CreateObject / CreateObjectAsync → VolumeRenderedObject
   │  单位立方体网格(VolumeContainer) + 体渲染材质 + 传输函数纹理
   ▼
GPU 片元着色器：对每个像素 射线求交 → 步进采样 → 传输函数 → Alpha 合成
   │
   ▼
屏幕图像（可叠加光照/阴影/切面/分割/多体）
```

## 4. 渲染方式分类（为什么选光线步进）

体渲染的主流实现方式：

| 方式 | 思路 | 优缺点 |
|---|---|---|
| **光线投射/步进（Ray Casting / Ray Marching）** | 每个像素发一条射线穿过体数据，逐点采样累加 | 质量高、可做 DVR/MIP/等值面；本项目采用 |
| 切片合成（Texture Slicing / 2D Texture Slicing） | 用一组平行平面切片采样 3D 纹理再混合 | 实现简单、快；质量与切片数相关 |
| 光栅化（Shear-Warp） | 视点变形+重投影 | 旧式、已少用 |
| 预积分 / 深度学习体渲染 | 高级改进 | 本项目未用 |

本项目选择的是**光线步进（Ray Marching）**：把每个像素当一条射线，用 GPU 并行计算，
质量高且灵活（同一框架能切换三种渲染模式）。

## 5. 三个必须记住的关键词

1. **密度（density）**：体素里存的数值，体渲染的「输入原料」。
2. **传输函数（Transfer Function, TF）**：把密度映射为颜色+透明度的「调色规则」。
3. **Alpha 合成（compositing）**：沿射线把各采样点的 RGBA 逐层混合成最终像素的过程。

三者关系：**密度 →（传输函数）→ RGBA →（沿射线 Alpha 合成）→ 像素颜色**。
