# 09 - 术语表

体渲染相关的中英对照速查表，随查随用。

## A. 数据与体素

| 英文 | 中文 | 说明 |
|---|---|---|
| Volume Data | 体数据 | 三维标量场 |
| Voxel | 体素 | 3D 网格上的一个格子（类比 2D 像素） |
| Density / Intensity | 密度 / 强度 | 体素里存的数值 |
| Scalar Field | 标量场 | 每点一个数值的场 |
| Resolution (dimX/Y/Z) | 分辨率 | 三个轴上的体素数 |
| Anisotropic spacing | 各向异性间距 | 三方向体素尺寸不同（DICOM 常见） |
| Hounsfield Unit (HU) | 亨氏单位 | CT 的密度单位 |
| Normalize | 归一化 | 缩放到 [0,1] |
| VASP / PARCHG | 材料科学电荷密度格式 | 本项目可导入 |
| NRRD / NIFTI / DICOM | 医学影像格式 | 本项目可导入 |

## B. 渲染算法

| 英文 | 中文 | 说明 |
|---|---|---|
| Ray Casting | 光线投射 | 逐像素发射线采样体数据 |
| Ray Marching | 光线步进 | 沿射线等距/等步采样 |
| Raymarching | 光线步进（同义） | 同上 |
| AABB | 轴对齐包围盒 | 本项目的求交对象（单位立方体） |
| Step Size | 步长 | 两次采样之间的距离 |
| Sampling Rate | 采样率 | 每射线采样次数（与步长反比） |
| Front-to-back | 从前到后 | DVR 的合成顺序 |
| Alpha Compositing | Alpha 合成 | 逐层混合 RGBA |
| Opacity Correction | 不透明度校正 | 采样率变化时的密度补偿 |
| Early Ray Termination | 早期终止 | 累计不透明度足够高就停止 |
| Jittering | 抖动 | 加随机偏移消除条带 |
| Banding | 条带/波纹伪影 | 等距采样引起的明暗波纹 |
| Depth Writing | 深度写入 | 写等效深度用于遮挡 |
| Transfer Function | 传输函数 | 密度→RGBA 的映射 |
| Control Point | 控制点 | 定义 TF 曲线的点 |
| Gradient | 梯度 | 密度变化方向 |
| Gradient Magnitude | 梯度幅值 | 密度变化剧烈程度 |
| Normal | 法线 | 表面方向（用梯度近似） |
| Phong Lighting | Phong 光照 | 漫反射+环境光+镜面 |
| Shadow Volume | 阴影体 | 预烘焙的 3D 阴影 |
| Cutout / Cross-section | 裁剪 / 切面 | 切掉部分体积便于观察 |
| Isosurface | 等值面 | 固定密度值的表面 |

## C. 渲染模式

| 缩写/英文 | 中文 | 说明 |
|---|---|---|
| DVR | 直接体渲染 | 传输函数 + Alpha 合成 |
| MIP | 最大强度投影 | 取射线最大密度 |
| Isosurface Rendering | 等值面渲染 | 求首个表面点 |
| Maximum Intensity Projection | 最大强度投影（全称） | = MIP |

## D. Unity / 工程

| 英文 | 中文 | 说明 |
|---|---|---|
| Fragment Shader | 片元着色器 | 逐像素执行（本项目主战场） |
| Vertex Shader | 顶点着色器 | 变换顶点 |
| Texture3D | 3D 纹理 | 存体数据 |
| RenderPipeline | 渲染管线 | Built-in / URP / HDRP |
| multi_compile | 多编译关键字 | 生成 shader 变体 |
| Shader Variant | 着色器变体 | 关键字组合的编译产物 |
| Compute Shader | 计算着色器 | 用于阴影体烘焙 |
| ScriptableObject | 可脚本化对象 | TF 的存储类型 |
| URP / HDRP | 通用/高清渲染管线 | Unity 的 SRP |

## E. 本项目专有名词

| 名词 | 含义 |
|---|---|
| `VolumeDataset` | 存体数据（data + dims + scale）的 ScriptableObject |
| `VolumeRenderedObject` | 场景中的体对象（挂体渲染组件） |
| `VolumeObjectFactory` | 创建体对象的工厂 |
| `TransferFunctionDatabase` | TF 默认值/预设 |
| `RuntimeVolumeLoader` | 示例工程的运行时加载器 |
| `VolumeViewerUI` | 示例工程的 IMGUI 控制面板 |
| `DatasetPathResolver` | 数据路径解析（StreamingAssets 优先） |
| `MrbExtractor` | 解包 .mrb(zip) 得到 NRRD 的编辑器工具 |
| `SegmentationOverlayLoader` | 加载分割标签并叠加 |
| `SlicePlaneBinder` | 把切片影像绑定到场景 Plane |
| `ApplyHounsfieldTransferFunction` | 按 HU 建 TF 的预设（示例工程） |
