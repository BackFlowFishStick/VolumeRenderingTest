# 07 - 采样、插值与图像质量

> 代码位置：`Runtime/Shaders/Include/VolumeRendering.hlsl`、
> `Runtime/Shaders/Include/TricubicSampling.cginc`、
> `Runtime/Utils/NoiseTextureGenerator.cs`。

## 1. 采样位置与插值

射线步进时，采样点几乎不会正好落在体素网格中心，
需要**插值**从周围体素估算该点的密度。

### 1.1 三线性插值（Trilinear，硬件默认）

- GPU 硬件对 3D 纹理默认做三线性插值（8 邻域）；
- 快，画质尚可；
- 低分辨率数据容易出现**阶梯/块状伪影（voxelization）**。

### 1.2 三三次插值（Tricubic，可选用）

- 开启 `CUBIC_INTERPOLATION_ON`（`SetCubicInterpolationEnabled(true)`）；
- 用 `TricubicSampling.cginc` 实现（`interpolateTricubicFast`），
  基于 **8 次三线性查询**模拟三次 B 样条（Danny Ruijters 的快速算法）；
- 平滑、抗块状伪影，但**更贵**；
- 数据纹理、梯度纹理、阴影纹理共用这套插值。

```hlsl
float getDensity(float3 pos) {
#if CUBIC_INTERPOLATION_ON
    return interpolateTricubicFast(_DataTex, sampler_DataTex, pos, _TextureSize).r;
#else
    return _DataTex.SampleLevel(sampler_DataTex, pos, 0).r;
#endif
}
```

## 2. 噪声抖动（Jittering）与条带伪影

### 问题：Banding（条带/波纹）

等距采样在**视角与采样方向接近平行**时，会出现明暗波纹。

### 解决：随机偏移

每条射线起点加一个随机偏移（`_NoiseTex` 提供随机值）：

```hlsl
ray.startPos += (JITTER_FACTOR * ray.direction * stepSize) * getNoise(uv).r;
```

- 噪声纹理 512×512，每个像素一个 [0,1) 随机值；
- `JITTER_FACTOR = 5.0`：偏移量是 5 个步长以内，打散采样相位；
- 代价极小，几乎必开。

## 3. 采样率与画质/性能

| `_SamplingRateMultiplier` | 效果 |
|---|---|
| 0.2（低） | 快，但易出现断层/闪烁/细节丢失 |
| 1.0（默认） | 均衡 |
| 2.0（高） | 细节更细腻，帧率下降明显 |

配合**不透明度校正**（见 02 章），采样率变化不会让「整体明暗」漂移，
只会影响细节平滑度。

## 4. 常见伪影与对策速查

| 伪影 | 原因 | 对策 |
|---|---|---|
| 条带 banding | 等距采样相位对齐 | 噪声抖动（已默认开） |
| 块状/阶梯 | 三线性插值、低分辨率 | 开三三次插值 |
| 闪烁/断层 | 采样率太低 | 提高 `_SamplingRateMultiplier` |
| 噪点花屏（开光照后） | 均匀区域梯度小、法线不准 | 提高光照梯度阈值下限 |
| 表面噪点（等值面） | `_MinGradient` 太小 | 调大 `minGradient` |
| 透明闪烁 | 采样率低 + alpha 抖动 | 提高采样率 |
