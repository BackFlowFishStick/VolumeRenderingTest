# 03 - 传输函数详解

> 代码位置：`Runtime/TransferFunction/TransferFunction.cs`（1D）、
> `Runtime/TransferFunction/TransferFunction2D.cs`（2D）、
> `Runtime/TransferFunction/TransferFunctionDatabase.cs`（默认/预设）。

## 1. 什么是传输函数（Transfer Function, TF）

体数据本身只有「一个密度值」，人类眼睛看不懂灰度。传输函数负责把密度映射成
**颜色（RGB）和透明度（A）**，从而把不同组织「染色 + 显隐」。

```
密度 density ──→ 传输函数 ──→ 颜色 (R,G,B) + 不透明度 (A)
```

这是体渲染的「灵魂」：**同一个数据，换个 TF 就换一种「看」法**。
例如把骨骼设成不透明白、软组织半透明红、空气全透明。

## 2. 1D 传输函数

### 2.1 基本思想

- 横轴：归一化密度 0~1；
- 纵轴（RGB 图）：颜色；
- 纵轴（Alpha 图）：不透明度 0~1。

用**控制点（Control Point）**来定义：用户添加若干「密度值 → 颜色/透明度」点，
程序在点之间插值生成一条连续曲线。

### 2.2 数据结构

```csharp
// TransferFunction.cs
[SerializeField] public List<TFColourControlPoint> colourControlPoints; // 颜色控制点
[SerializeField] public List<TFAlphaControlPoint>  alphaControlPoints;  // 透明度控制点
```

### 2.3 生成纹理（关键实现）

TF 最终会被**烘焙成一张 2D 纹理 `_TFTex`**，宽 1024、高 2，
格式 `RGBAHalf`/`RGBAFloat`。片元着色器只需一次 `tex2D(_TFTex, float2(density,0))`
就能查到颜色+不透明度。

生成过程：

1. 把颜色/透明度控制点按密度排序；
2. 自动补全两端（密度 0 和 1）保证曲线连续；
3. 对每个 x（0~1023）：找到左右两个控制点，按相对位置做插值；
4. 用 `Mathf.SmoothStep` 平滑（避免硬边）；
5. `texture.wrapMode = Clamp` 并上传。

```csharp
// 核心插值伪代码
for (int iX = 0; iX < TEXTURE_WIDTH; iX++) {
    float t = iX / (float)(TEXTURE_WIDTH - 1);
    // 找左右颜色点、左右 alpha 点
    // 颜色：线性插值；alpha：线性插值
    // 都过 SmoothStep 平滑
    tfCols[iX] = colorAtT; // RGBA
}
```

### 2.4 默认 1D TF（TransferFunctionDatabase）

```csharp
// 颜色点
(0.0000, (0.11, 0.14, 0.13))
(0.2415, (0.469, 0.354, 0.223))
(0.3253, (1.0, 1.0, 1.0))
// 透明度点
(0.0000, 0.0) (0.1787, 0.0) (0.2000, 0.024) (0.2800, 0.03)
(0.4000, 0.546) (0.5470, 0.5266)
```

即：低密度（气体/皮肤边缘）基本透明，中高密度（组织/骨）才逐渐显色。

### 2.5 本项目示例：HU 预设

`VolumeRenderingSample` 的 `ApplyHounsfieldTransferFunction` 按 CT 的 HU 值构造 TF：

| 密度(HU) | 教学版 alpha | 标准版 alpha | 颜色 |
|---|---|---|---|
| -1000（空气） | 0 | 0 | 深蓝灰 |
| 0（水/软组织） | 0 | 0.03 | 灰 |
| 150（组织） | 0 | 0.20 | 灰褐 |
| 800（骨） | 0 | 0.85 | 白 |
| 3000（密骨） | 0 | 0.95 | 白 |

> 教学版把 CT 本体全部置为透明，只留分割叠加的结构色 → 用来「只看器官」。

## 3. 2D 传输函数（TransferFunction2D）

### 3.1 为什么需要 2D

1D TF 只按「密度」区分，但很多组织密度接近（软组织 vs 水肿），
却**梯度（梯度幅值）不同**——组织边界处密度变化剧烈。2D TF 用
**横轴=密度、纵轴=梯度幅值**，能同时按两者染色，区分边界与内部。

### 3.2 数据结构

```csharp
// TransferFunction2D.cs
public struct TF2DBox {
    public Color colour;   // 盒子颜色
    public float alpha;    // 盒内 alpha
    public float minAlpha; // 边缘最小 alpha
    public Rect rect;      // 密度/梯度范围
}
public List<TF2DBox> boxes;
```

用户用「矩形盒子」在二维平面上定义：处于某密度区间 + 某梯度区间的体素显示某色。

### 3.3 生成纹理

- 纹理大小 **512×512**，格式 `RGBAHalf`/`RGBAFloat`；
- 横轴 = 密度，纵轴 = 梯度幅值（归一化）；
- 遍历每个像素，若落在某盒子内则填盒子颜色，alpha 从 `alpha` 到 `minAlpha`
  按离中心距离衰减；
- 片元着色器：`getTF2DColour(density, gradientMagnitude)` 一次查表。

> 注意：代码注释标明 2D TF 仍是 **WIP（未完成品）**，重叠盒子的合成未处理。

## 4. 1D vs 2D 对比

| 维度 | 1D TF | 2D TF |
|---|---|---|
| 输入轴 | 密度 | 密度 + 梯度幅值 |
| 控制方式 | 控制点 | 矩形盒子 |
| 纹理 | 1024×2 | 512×512 |
| 优点 | 简单、直观 | 能区分同密度不同边界的组织 |
| 缺点 | 同密度组织难区分 | 调节复杂、WIP |
| 切换 | `TFRenderMode.TF1D` | `TFRenderMode.TF2D`（着色器 `TF2D_ON`） |

## 5. 常见操作 API

| 操作 | API |
|---|---|
| 加颜色点 | `tf.AddControlPoint(new TFColourControlPoint(x, color))` |
| 加透明度点 | `tf.AddControlPoint(new TFAlphaControlPoint(x, alpha))` |
| 重新生成纹理 | `tf.GenerateTexture()` |
| 拿到纹理 | `tf.GetTexture()` |
| 应用到体对象 | `volObj.SetTransferFunction(tf)` |
| 换 1D/2D | `volObj.SetTransferFunctionMode(TFRenderMode.TF1D/TF2D)` |

> 容易踩的坑：`CreateTransferFunction()` 在创建时已用默认点生成了纹理缓存，
> 改完控制点后必须调用 `GenerateTexture()`，否则 `GetTexture()` 返回旧缓存。
