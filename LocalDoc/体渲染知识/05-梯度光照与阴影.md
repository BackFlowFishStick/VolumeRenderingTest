# 05 - 梯度、光照与阴影

> 代码位置：
> 梯度计算 `Runtime/Gradients/*.cs`；
> 光照 `VolumeRendering.hlsl` 的 `calculateLighting` / `getGradient`；
> 阴影 `Runtime/Lighting/ShadowVolumeManager.cs` + `Runtime/Resources/ShadowVolume.compute`。

## 1. 为什么需要梯度（Gradient）

**梯度**是密度场的「变化方向」：`∇f = (∂f/∂x, ∂f/∂y, ∂f/∂z)`。
在体渲染里有三个用途：

1. **当法线**：密度变化最快的方向近似就是「表面法线」，用于光照；
2. **2D 传输函数的第二轴**：梯度幅值区分「边界 vs 内部」；
3. **等值面判定**：梯度幅值大的点才是表面（见 04 章）。

## 2. 梯度如何计算（离线生成）

梯度在**导入/改设置时一次性算好**，存进 3D 纹理 `_GradientTex`，
片元着色器直接查表，避免每帧重算。

### 2.1 支持四种梯度类型（`GradientType`）

| 类型 | 计算方式 | 说明 |
|---|---|---|
| `CentralDifference` | 中心差分 `(f(x+1)-f(x-1))/2` | 默认，快 |
| `SmoothedCentralDifference` | 先对数据做**双边滤波**再中心差分 | 需要 SimpleITK |
| `Sobel` | 3D Sobel 卷积核（27 邻域） | 抗噪更好 |
| `SmoothedSobel` | 先平滑再 Sobel | 需要 SimpleITK |

`CentralDifferenceGradientComputator` 的实现（简化）：

```csharp
return new Vector3((x2 - x1) / maxRange,
                   (y2 - y1) / maxRange,
                   (z2 - z1) / maxRange);
```

> 说明：`Smoothed*` 变体依赖 SimpleITK（`UVR_USE_SIMPLEITK` 宏）。
> 没有启用 SimpleITK 时，平滑版本会警告并退化为不平滑。

### 2.2 梯度纹理格式

- 大小 = 体数据分辨率（如 512×512×320）；
- 格式 `RGBAHalf`/`RGBAFloat`；
- **RGB = 梯度方向分量，A = 归一化密度**（复用了 alpha 通道，省一张纹理）。

## 3. 光照（Phong 光照模型）

着色器 `calculateLighting` 用的是经典 **Phong**：

```hlsl
// 若法线与视线反向，翻转法线（优化版）
normal *= (step(0.0, dot(normal, eyeDir)) * 2.0 - 1.0);

float ndotl = max(dot(normal, lightDir), 0);
float3 diffuse  = ndotl * col;                    // 漫反射
float3 ambient  = AMBIENT_LIGHTING_FACTOR * col;  // 环境光(0.2)
float3 r = normalize(reflect(-lightDir, normal));
float3 specular = pow(max(dot(r, eyeDir), 0), 32) * specularIntensity; // 镜面
result = diffuse + ambient + specular;
```

### 3.1 光源方向（LightSource）

| 设置 | 行为 |
|---|---|
| `ActiveCamera`（默认） | 光照方向 = 视线方向（“自发光”感，最稳） |
| `SceneMainLight` | 用场景主平行光方向（`USE_MAIN_LIGHT`） |

### 3.2 梯度光照阈值

体素在均匀区域时梯度很小，法线不可靠，直接光照会出噪点。
`gradientLightingThreshold`（默认 `(0.005, 0.02)`）做平滑过渡：

```hlsl
float factor = smoothstep(start, end, gradMag); // 低梯度→不光照，高梯度→光照
src.rgb = lerp(src.rgb, shaded, factor);
```

## 4. 阴影体（Shadow Volume）

体渲染里没有传统阴影贴图，本项目用**预烘焙 3D 阴影纹理**：

### 流程（ShadowVolumeManager + ShadowVolume.compute）

1. 建一张 **512×512×512** 的 3D RenderTexture（`RHalf`）；
2. Compute Shader 从**光源方向**对每个体素发一条短射线（32 步），
   沿途累加被遮挡的不透明度 `calculateShadow`，结果存进 `_ShadowVolume`；
3. DVR 主循环里：`src.rgb *= (1.0 - shadow)` 应用阴影；
4. 由于计算量很大，按 **5×5×5 分块、每帧只算一块**（分摊到多帧）。

### 关键点

- 需要平台支持 Compute Shader（`SystemInfo.supportsComputeShaders`）；
- 阴影会随光源移动而**重新烘焙**，因此有 `isDirty` + 冷却时间机制；
- 开销较大，按需开启（`SHADOWS_ON` 关键字）。
