# 02 - 光线步进算法详解（本项目核心）

> 这是整个体渲染中最重要的一章。所有代码都在：
> `UnityVolumeRendering/Runtime/Shaders/Include/VolumeRendering.hlsl`
> 入口着色器：`Runtime/Shaders/BuiltIn|URP|HDRP/DirectVolumeRenderingShader.shader`

## 1. 宏观流程（每个像素执行）

对屏幕上属于体对象的每一个片元（fragment）：

1. **求射线**：从相机经该像素发一条视线，求它与体包围盒（AABB）的交点，得到
   `startPos`（进入点）和 `endPos`（离开点）。
2. **定步进参数**：计算步长 `stepSize` 和步数 `numSteps`。
3. **循环采样**：从 `startPos` 沿射线每步采一次 3D 纹理，得到该位置的密度。
4. **映射**：用传输函数把密度映射为 RGBA。
5. **合成**：按「从前到后」把本次采样合成进累积颜色。
6. **提前终止**：累计不透明度接近 1 时停止（可选）。
7. 可选：噪声抖动、切面裁剪、光照、阴影、深度写入。

## 2. 射线生成：`getRayBack2Front` / `getRayFront2Front`

着色器里的体对象是一个**单位立方体**（坐标 0~1，对应体素纹理 0~1 UV），
渲染时 `Cull Front`（只画背面/内部），因此片元都在立方体内部或背面。

```hlsl
// 取视线方向（透视/正交）
float3 getViewRayDir(float3 vertexLocal) {
    if(unity_OrthoParams.w == 0) { // 透视
        return normalize(ObjSpaceViewDir(float4(vertexLocal, 0.0f)));
    } else { // 正交
        float3 camfwd = mul((float3x3)UVR_MATRIX_CAMERA_TO_WORLD, float3(0,0,-1));
        float4 camfwdobjspace = mul(UVR_MATRIX_WORLD_TO_OBJECT, camfwd);
        return normalize(camfwdobjspace);
    }
}

// 求射线与 [0,1]^3 立方体的交点（进入 tNear / 离开 tFar）
float2 intersectAABB(float3 rayOrigin, float3 rayDir, float3 boxMin, float3 boxMax) {
    float3 tMin = (boxMin - rayOrigin) / rayDir;
    float3 tMax = (boxMax - rayOrigin) / rayDir;
    float3 t1 = min(tMin, tMax);
    float3 t2 = max(tMin, tMax);
    float tNear = max(max(t1.x, t1.y), t1.z);
    float tFar  = min(min(t2.x, t2.y), t2.z);
    return float2(tNear, tFar);
}
```

`getRayBack2Front` 会做「相机在体内」的特殊处理（限制 tFar 到视点距离），
`getRayFront2Front` 则把方向反转，使采样从**靠近相机的一端**开始。

## 3. 步进参数：`initRaymarch`

```hlsl
raymarchInfo.stepSize = 1.732f /*立方体对角线 √3*/ / maxNumSteps;
raymarchInfo.numSteps  = clamp(|tNear - tFar| / stepSize, 1, maxNumSteps);
```

- **MAX_NUM_STEPS**：DVR/MIP 用 512，等值面用 1024。
- `_SamplingRateMultiplier`（0.2~2.0）会缩放实际采样率：
  `samplingRate = (int)(MAX_NUM_STEPS * _SamplingRateMultiplier)`。
- 步长越小、步数越多 → 画质越高、越慢；反之越快但容易出现断层/闪烁。

## 4. 核心采样与合成循环（DVR）

以下是 `volrend_dvr` 的**骨架**（伪代码 + 关键公式）：

```hlsl
for (int iStep = 0; iStep < numSteps; iStep++) {
    float3 currPos = lerp(startPos, endPos, t); // 当前采样位置

    // 可选：切面/裁剪盒裁剪
    if (IsCutout(currPos)) continue;

    float density = getDensity(currPos);        // 采样 3D 纹理

    // 可见值域窗口：只渲染 [MinVal, MaxVal] 内的密度
    if (density < _MinVal || density > _MaxVal) continue;

    // 传输函数查表得到颜色+不透明度
    float4 src = getTF1DColour(density);        // 1D TF
    // 2D TF:  getTF2DColour(density, gradMag);
    if (src.a == 0.0) continue;                 // 完全透明则跳过

    // 可选：光照/阴影（见第 05 章）

    // 不透明度校正：保证不同采样率下整体密度一致
    float blendFactor = 1.0f / _SamplingRateMultiplier;
    src.a = 1.0f - pow(1.0f - src.a, blendFactor);
    src.rgb *= src.a;

    // 从前到后 Alpha 合成
    col = (1.0f - col.a) * src + col;

    // 早期终止：累计不透明度足够高就跳出
    if (col.a > OPACITY_THRESHOLD) break;   // 阈值 = 1 - 1/255
}
```

### 4.1 从前到后（front-to-back）合成公式

`col = (1 - col.a) * src + col` 等价于：

```
outRGB  = srcRGB + colRGB * (1 - srcAlpha)
outAlpha = srcAlpha + colAlpha * (1 - srcAlpha)
```

含义：先看到的不透明层会遮挡后面看不到的内容。**顺序必须是前→后**，
这正是 `getRayFront2Front` 把射线方向反过来的原因。

### 4.2 不透明度校正（Opacity Correction）

不同采样率下如果直接用采样得到的 alpha，数据密度会被「重复叠加」。
用公式 `src.a = 1 - (1 - src.a)^(1/采样率倍率)` 校正，
使得采样步数变化时整体观感不变（这是体渲染的重要概念）。

### 4.3 噪声抖动（Jittering）

在 `startPos` 上加一个小的随机偏移，避免等距采样产生**条带（banding）伪影**：

```hlsl
ray.startPos += (JITTER_FACTOR * ray.direction * stepSize) * getNoise(uv).r;
```

## 5. 深度写入（DEPTHWRITE_ON）

体渲染是半透明的，但为了**多个体对象/普通网格正确遮挡**，会计算一个
「等效深度」并写入 `SV_DEPTH`：

- 记录累计不透明度超过 0.15 的第一个位置作为深度；
- 若整条射线都没命中（透明），写入一个很大的深度值。
- `localToDepth()` 把局部坐标转成裁剪空间深度。

打开深度写入会略微降低性能；关闭后体与体/体与网格的相交会乱。

## 6. 三条射线在哪区分三种模式？

`volrend` 按关键字分发到三个函数：

| 函数 | 关键字 | 采样顺序 | 输出 |
|---|---|---|---|
| `volrend_dvr` | `MODE_DVR` | 前→后 | 传输函数+Alpha 合成（见上文） |
| `volrend_mip` | `MODE_MIP` | 后→前 | 记录**最大密度**及其位置 |
| `volrend_surf` | `MODE_SURF` | 前→后 | 命中「密度在窗口内且梯度够大」的第一个点就停 |

三种模式的详细区别见 [04-渲染模式详解](04-渲染模式详解.md)。
