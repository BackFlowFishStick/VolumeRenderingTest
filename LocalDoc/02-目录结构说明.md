# 02 - 目录结构说明

仓库根目录为 `UnityVolumeRendering/`（UPM 包布局，同时内含 git 仓库，356 次提交）。

## 顶层目录/文件

| 路径 | 说明 |
| --- | --- |
| `Runtime/` | 运行时代码（C# 脚本、着色器、资源），打包进用户工程 |
| `Editor/` | 编辑器专用代码（菜单、自定义 Inspector、导入窗口、脚本化导入器） |
| `ThirdParty/` | 第三方库源码：`Nifti.NET`、`openDicom`（含 `UnityVolumeRendering.3rdParty.asmdef`） |
| `Documentation~/` | 官方文档（Markdown + 截图 + MANUAL.pdf） |
| `SampleProject~/` | 示例 Unity 工程（TestScene 场景、CameraController、SampleData 数据） |
| `scripts/` | 构建/CI 辅助脚本（`ExportUnityPackage.py`、`DocsToPDF.py`、`ci/activate-license.sh`） |
| `.github/workflows/` | GitHub Actions 打包工作流（Unity 2022.3 / 6000.0） |
| `package.json` | UPM 包元数据（名称、版本、依赖、示例注册） |
| `README.md` | 项目主 README（快速入门 + FAQ） |
| `CHANGELOG.md` | 变更日志 |
| `LICENSE.md` | MIT 许可证 |
| `CREDITS.md` | 贡献者名单 |
| `CONTRIBUTING.md` | 贡献指南 |
| `TestChecklist.md` | PR 测试清单 |
| `Third Party Notices.md` | 第三方许可声明 |
| `.gitattributes` / `.gitignore` | git 配置 |

## Runtime/ 结构

| 目录 | 职责 |
| --- | --- |
| `Runtime/Gradients/` | 梯度计算（CentralDifference / Sobel 及其平滑变体） |
| `Runtime/GUI/` | 运行时 IMGUI：`RuntimeFileBrowser`、颜色选择器、测量工具、运行时传输函数编辑 |
| `Runtime/Importing/` | 导入框架：`ImporterFactory`、`DatasetImporterUtility`、RAW/DICOM/NIFTI/VASP/图像序列各导入器、`.ini` 解析 |
| `Runtime/Lighting/` | `LightSource`（光源枚举）、`ShadowVolumeManager`（阴影体） |
| `Runtime/Progress/` | 异步进度系统：`ProgressHandler`、`IProgressView`、`EditorProgressView` |
| `Runtime/Segmentation/` | 分割支持：`SegmentationBuilder`（TotalSegmentator 标签映射）、`SegmentationLabel`、渲染模式 |
| `Runtime/Shaders/` | 着色器（见 `06-渲染管线与着色器.md`） |
| `Runtime/TransferFunction/` | 1D/2D 传输函数、控制点、传输函数数据库 |
| `Runtime/Utils/` | 工具类：`AsyncHelper`、直方图纹理、噪声纹理、管线检测 |
| `Runtime/VolumeData/` | `VolumeDataset`：体数据核心数据结构（3D 密度数组 + 数据/梯度纹理） |
| `Runtime/VolumeObject/` | `VolumeRenderedObject`、`VolumeObjectFactory`、切面/裁剪/切片、材质与着色器工厂 |
| `Runtime/VolumeQueries/` | `VolumeRaycaster`：CPU 光线投射 |
| `Runtime/Resources/` | 内置资源：预置体（VolumeContainer、SlicingPlane、CrossSectionPlane、CutoutBox/Sphere）、图标、DICOM 字典、Compute Shader |

## Editor/ 结构

| 目录/文件 | 职责 |
| --- | --- |
| `VolumeRendererEditorFunctions.cs` | “Volume Rendering” 菜单项（导入、切面、传输函数、切片渲染器、设置等） |
| `VolumeRenderedObjectCustomInspector.cs` | 体渲染对象自定义 Inspector（渲染模式、光照、分割、叠加等） |
| `TransferFunctionEditorWindow.cs` / `TransferFunction2DEditorWindow.cs` | 1D/2D 传输函数编辑窗口 |
| `SliceRenderingEditorWindow.cs` | 切片渲染器窗口 |
| `CrossSectionPlaneEditorWindow.cs` | 切面选择窗口 |
| `RAWDatasetImporterEditorWIndow.cs` / `ImportSettingsEditorWindow.cs` / `ValueRangeEditorWindow.cs` | RAW 导入参数、全局设置、值域窗口 |
| `EditorDatasetImporter.cs` / `EditorDatasetImportUtils.cs` | 编辑器端导入工具（可选降采样等） |
| `ScriptedImporters/` | 脚本化导入器（RAW / 图像文件 / 传输函数），支持拖入 Assets |
| `DragDropHandler.cs` | 拖拽导入处理 |
| `SimpleITK/SimpleITKManager.cs` | SimpleITK 二进制下载与启用管理 |
| `GUIUtils/ResizableArea.cs` | 编辑器 GUI 辅助 |

## 其他说明

- 仓库内 git 根在 `UnityVolumeRendering/`，当前外层目录 `TestVolumeRendering` 仅包含该子仓库。
- 官方文档（`Documentation~`）仍是权威参考，本 `LocalDoc` 是基于其整理的中文速查文档。
