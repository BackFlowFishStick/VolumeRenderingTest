# 10 - 快速上手指南

## 1. 安装方式

本仓库是 **UPM 包**，三种安装方式：

### 方式 A：Git URL（推荐，用于自己的工程）
Unity Package Manager → “+” → “Add package from git URL…”，输入：
```
https://github.com/mlavik1/UnityVolumeRendering.git
```
指定版本（可选）：`...#v1.0.0`

### 方式 B：manifest.json
在工程 `Packages/manifest.json` 增加：
```json
"com.mlavik1.easyvolumerenderer": "https://github.com/mlavik1/UnityVolumeRendering.git"
```

### 方式 C：本地开发 / 本地引用
打开本仓库的 `SampleProject~/`（Unity 6000.0.25f1），其 manifest 已用 `file:../../` 指向包根目录。
或者把 `UnityVolumeRendering/` 整个目录放进自己工程的 `Packages/` 下。

## 2. 导入示例

1. Package Manager → 找到 “Easy Volume Renderer” → Samples 选项卡 → 导入
   “Basic Demo” 与 “Sample Data”。
2. 打开导入的 `TestScene.unity`。
3. 菜单 `Volume Rendering` → `Load dataset` → `Load raw dataset`，选择 `VisMale.raw`。
4. 使用 .ini 提供的默认参数，点 import。

## 3. 导入自己的数据

| 数据 | 操作 |
| --- | --- |
| RAW | `Load raw dataset` → 填维度/格式/端序/跳过字节（或用同名 .ini） |
| DICOM | `Load DICOM` → 选包含所有切片的文件夹（多 series 会生成多个对象） |
| NRRD | 先到 `Volume Rendering/Settings` 开启 SimpleITK，再 `Load NRRD dataset` |
| NIFTI | `Load NIFTI dataset`（.nii / .nii.gz；建议启用 SimpleITK） |
| VASP/PARCHG | `Load PARCHG dataset` |
| 图像序列 | `Load image sequence` → 选含 JPG/PNG 切片序列的文件夹 |

也可直接把文件**拖入 Assets**（RAW/NRRD/NIFTI/PARCHG），或 **Assets 右键** → `Volume Rendering` → `Import dataset`。

## 4. 调整渲染

1. 选中体对象，Inspector 中 “Volume Rendered Object”：
   - 切换 **Render mode**：DVR / MIP / Isosurface；
   - 调整 **Visible value range**（可见密度范围）；
   - 打开 **Lighting**（含梯度类型、光源、阈值、阴影体）；
   - 配置 **Transfer function**（1D/2D，点 “Edit transfer function” 打开编辑器）。
2. 切面：`Volume Rendering` → `Cross section` → 平面/盒式/球式裁剪。
3. 切片视图：`Volume Rendering` → `Slice renderer`。

## 5. 性能建议

- 保持 **Early ray termination** 开启；调低 shader 中 `MAX_NUM_STEPS`（`VolumeRendering.hlsl`）。
- **Cubic interpolation** 与 **Shadow volume** 开销大，按需开启。
- 光照与立体渲染（VR）会增加开销；VR 下可关闭 `DEPTHWRITE_ON` 变体。
- 大体积数据导入时允许降采样；WebGL 需开启 `ALLOW_MEMORY_GROWTH` 且无法运行时读本地文件。

## 6. 常见问题（摘自官方 FAQ）

- **真实尺寸**：导入默认归一化缩放，保持真实比例可把外层 GameObject 的 scale 设为 (1,1,1)。
- **VR**：Built-in 与 URP 支持良好，HDRP 未官方测试；双摄像机开销较大。
- **WebGL**：可用但内存受限；需在编辑器预导入数据或使用 UnityWebRequest 下载。
- **更好看**：开启 cubic 采样、阴影体、调高 `MAX_NUM_STEPS`。
- **点击命中**：用 `VolumeRaycaster.RaycastScene(ray, out hit)`。
- **更多帮助**：在 GitHub 仓库创建 issue。
