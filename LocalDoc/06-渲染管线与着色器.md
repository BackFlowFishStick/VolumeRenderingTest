# 06 - 渲染管线与着色器

## 1. 渲染原理（GPU Raymarching）

体对象渲染时使用一个单位立方体网格（`VolumeContainer.prefab`，带 `MeshRenderer`），
材质使用体渲染着色器。在**片元着色器**中对每个像素执行**光线步进**：

1. 计算视点到体包围盒（AABB）的射线（`intersectAABB`），得到进入/离开点；
2. 在射线方向按固定步长采样体数据纹理 `_DataTex`；
3. 根据当前渲染模式处理采样值：
   - **DVR**：传输函数查表得到颜色+不透明度，从前到后 alpha 混合累加（带不透明度校正）；
   - **MIP**：记录射线上的最大密度；
   - **Isosurface**：命中密度在可见值域且梯度幅值超过阈值时，用梯度作法线做光照并停止；
4. 可选：切面裁剪（`IsCutout`）、三三次插值（`TricubicSampling.cginc`）、
   噪声抖动、光照、阴影纹理查询、多体叠加/隔离、早期终止；
5. 输出颜色，可选写深度（`DEPTHWRITE_ON`，用于多数据集相交）。

核心逻辑在 **`Runtime/Shaders/Include/VolumeRendering.hlsl`**：
- `volrend_dvr` / `volrend_mip` / `volrend_surf` 三种模式的 raymarching 实现；
- `getTF1DColour` / `getTF2DColour` 传输函数采样；
- `calculateLighting`（Phong：漫反射+环境光+镜面）、`getGradient`、`calculateShadow`；
- `MAX_NUM_STEPS`：DVR/MIP 512、Isosurface 1024（可在 shader 中调低以提升性能）。

## 2. 着色器文件结构

| 路径 | 说明 |
| --- | --- |
| `Runtime/Shaders/BuiltIn/` | Built-in 管线着色器（DirectVolumeRenderingShader、SliceRenderingShader、CrossSectionPlane/Sphere、TransferFunction 系列） |
| `Runtime/Shaders/URP/` | URP 版本（同名文件） |
| `Runtime/Shaders/HDRP/` | HDRP 版本 |
| `Runtime/Shaders/Include/` | 共享逻辑：`VolumeRendering.hlsl`（核心）、`TricubicSampling.cginc`（三三次插值）、`VolumeCutout.cginc`（裁剪）、`BackwardsCompatibility.hlsl` |

`ShaderFactory`（`Runtime/VolumeObject/ShaderFactory.cs`）按当前渲染管线返回对应着色器，
`RenderPipelineHelper`（`Runtime/Utils/RenderPipelineHelper.cs`）负责检测管线。

## 3. 着色器关键字（multi_compile）

| 关键字 | 作用 |
| --- | --- |
| `MODE_DVR` / `MODE_MIP` / `MODE_SURF` | 三种渲染模式 |
| `TF2D_ON` | 使用 2D 传输函数 |
| `CROSS_SECTION_ON` | 启用切面/裁剪 |
| `LIGHTING_ON` | 启用光照 |
| `SHADOWS_ON` | 启用阴影体 |
| `DEPTHWRITE_ON` / `DEPTHWRITE_OFF` | 深度写入开关 |
| `RAY_TERMINATE_ON` | 早期光线终止 |
| `USE_MAIN_LIGHT` | 使用场景主光源方向 |
| `CUBIC_INTERPOLATION_ON` | 三三次插值 |
| `SECONDARY_VOLUME_ON` | 次级体数据（PET 叠加） |
| `MULTIVOLUME_NONE` / `MULTIVOLUME_OVERLAY` / `MULTIVOLUME_ISOLATE` | 多体模式 |

## 4. Compute Shader 与纹理

| 资源 | 用途 |
| --- | --- |
| `Runtime/Resources/ShadowVolume.compute` | 从光源方向计算 3D 阴影体纹理 |
| `Runtime/Resources/ComputeHistogram.compute` | GPU 直方图计算（传输函数编辑器用） |
| `Runtime/Resources/Icons/` | 运行时 GUI 图标 |
| `Runtime/Textures/CrossSectionPlaneTexture.png` | 切面纹理 |

## 5. 其他渲染相关

- **切片着色器**（`SliceRenderingShader`）：在平面网格上重采样 `_DataTex` 显示某一切片的密度，
  配合 `SlicingPlane` 组件与 `EditSliceGUI`。
- **传输函数着色器**：`TransferFunctionShader`（1D 编辑预览）、`TransferFunction2DShader`、
  `TransferFunctionPaletteShader`（调色板）。
- **兼容性**：`BackwardsCompatibility.hlsl` 提供跨管线矩阵宏（`UVR_MATRIX_*`），
  使 Built-in/URP/HDRP 共用同一份 hlsl。
- **立体渲染**：片元着色器使用 `UNITY_VERTEX_OUTPUT_STEREO` / `UNITY_SETUP_STEREO_EYE_INDEX_POST_VERTEX`
  支持 VR 双摄像机。
