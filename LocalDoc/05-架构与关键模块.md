# 05 - 架构与关键模块

## 1. 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│  Editor（编辑器层）                                          │
│  菜单 / Inspector / 各 EditorWindow / ScriptedImporters      │
│  SimpleITKManager / 拖拽导入 / 降采样提示                     │
└──────────────────────────────┬──────────────────────────────┘
                               │ 编辑器操作
┌──────────────────────────────▼──────────────────────────────┐
│  Runtime（运行时核心）                                       │
│                                                             │
│  Importing  ──► VolumeDataset ──► VolumeObjectFactory        │
│  (各 Importer)    (3D密度+纹理)      │                       │
│                                     ▼                        │
│                    VolumeRenderedObject（MonoBehaviour）      │
│                      ├─ TransferFunction (1D/2D)             │
│                      ├─ CrossSectionManager（切面/裁剪）       │
│                      ├─ ShadowVolumeManager（阴影体）          │
│                      ├─ Segmentation / SecondaryVolume        │
│                      └─ Material + Shader（DVR/MIP/SURF）     │
│  GUI（运行时 IMGUI）/ Progress / VolumeRaycaster / Utils      │
└──────────────────────────────┬──────────────────────────────┘
                               │ 材质属性 / 关键字
┌──────────────────────────────▼──────────────────────────────┐
│  Shaders（Built-in / URP / HDRP）                            │
│  VolumeRendering.hlsl（核心 raymarching 逻辑）                │
│  TricubicSampling.cginc / VolumeCutout.cginc                │
│  ShadowVolume.compute / ComputeHistogram.compute             │
└─────────────────────────────────────────────────────────────┘
```

## 2. 核心类说明

### Runtime

| 类 | 路径 | 职责 |
| --- | --- | --- |
| `VolumeDataset` | `Runtime/VolumeData/VolumeDataset.cs` | 体数据核心：float 密度数组、维度、缩放/旋转、数据纹理与梯度纹理（懒加载 + 异步） |
| `VolumeRenderedObject` | `Runtime/VolumeObject/VolumeRenderedObject.cs` | 每个体对象的主组件（`[ExecuteInEditMode]`）：持有数据集、传输函数、材质；管理渲染模式/光照/分割/叠加等所有设置 |
| `VolumeObjectFactory` | `Runtime/VolumeObject/VolumeObjectFactory.cs` | 从 `VolumeDataset` 创建 `VolumeRenderedObject`（加载 VolumeContainer 预置体、创建材质/传输函数/噪声纹理）；也负责生成切面/裁剪体 |
| `MaterialFactory` / `ShaderFactory` | `Runtime/VolumeObject/` | 按当前渲染管线（Built-in/URP/HDRP）创建材质与选择着色器 |
| `ImporterFactory` | `Runtime/Importing/ImporterFactory.cs` | 按格式返回最佳导入器（含 SimpleITK 回退逻辑） |
| `RawDatasetImporter` / `DICOMImporter` / `NiftiImporter` / `ParDatasetImporter` / `ImageSequenceImporter` | `Runtime/Importing/...` | 各格式导入器 |
| `TransferFunction` / `TransferFunction2D` | `Runtime/TransferFunction/` | 传输函数与纹理生成；`TransferFunctionDatabase` 提供默认/预设 |
| `CrossSectionManager` | `Runtime/VolumeObject/CrossSectionManager.cs` | 管理最多 8 个切面/裁剪体，向材质写入矩阵与类型 |
| `CrossSectionPlane` / `CutoutBox` / `CutoutSphere` / `SlicingPlane` | `Runtime/VolumeObject/` | 交互式裁剪/切片组件 |
| `ShadowVolumeManager` | `Runtime/Lighting/ShadowVolumeManager.cs` | 阴影体计算与分块更新 |
| `SegmentationBuilder` | `Runtime/Segmentation/SegmentationBuilder.cs` | 自动识别分割标签并映射 TotalSegmentator 解剖学名称与颜色 |
| `VolumeRaycaster` | `Runtime/VolumeQueries/VolumeRaycaster.cs` | CPU 光线投射，返回最近命中点（含切面裁剪） |
| `ProgressHandler` / `EditorProgressView` | `Runtime/Progress/`、`Editor/` | 异步进度管理 |
| `RuntimeGUI` / `RuntimeFileBrowser` / `DistanceMeasureTool` / `EditSliceGUI` 等 | `Runtime/GUI/` | 运行时 IMGUI 界面 |

## 4. 关键设计点

- **纹理驱动渲染**：数据以 `Texture3D` 上传 GPU，梯度以 `Texture3D` 存储，着色器按需采样。
- **着色器关键字驱动**：所有渲染特性（模式/光照/阴影/切面/多体/深度写入/三三次插值）通过
  `#pragma multi_compile` 关键字开关，避免运行时分支开销。
- **材质为实例**：每个体对象持有独立材质实例，互不干扰。
- **异步友好**：纹理创建与导入均有 Async 版本，并用 `SemaphoreSlim` 保证线程安全。
- **编辑器/运行时统一**：核心逻辑全部在 Runtime 程序集，运行时也能创建体对象（如运行时 GUI）。
