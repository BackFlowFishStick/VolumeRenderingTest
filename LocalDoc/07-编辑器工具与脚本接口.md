# 07 - 编辑器工具与脚本接口

## 1. “Volume Rendering” 菜单项

定义于 `Editor/VolumeRendererEditorFunctions.cs`：

| 菜单 | 功能 |
| --- | --- |
| `Volume Rendering/Load dataset/Load raw dataset` | 打开 RAW 导入窗口 |
| `Volume Rendering/Load dataset/Load DICOM` | 选择 DICOM 文件夹并异步导入 |
| `Volume Rendering/Load dataset/Load NRRD dataset` | 导入 NRRD（需 SimpleITK） |
| `Volume Rendering/Load dataset/Load NIFTI dataset` | 导入 NIFTI |
| `Volume Rendering/Load dataset/Load image file` | 通用单文件导入（自动识别） |
| `Volume Rendering/Load dataset/Load PARCHG dataset` | 导入 VASP/PARCHG |
| `Volume Rendering/Load dataset/Load image sequence` | 导入图像序列文件夹 |
| `Volume Rendering/Cross section/Cross section plane` | 生成切面平面 |
| `Volume Rendering/Cross section/Box cutout` | 生成盒式裁剪 |
| `Volume Rendering/Cross section/Sphere cutout` | 生成球式裁剪 |
| `Volume Rendering/1D Transfer Function` | 打开 1D 传输函数编辑窗口 |
| `Volume Rendering/2D Transfer Function` | 打开 2D 传输函数编辑窗口 |
| `Volume Rendering/Slice renderer` | 打开切片渲染器窗口 |
| `Volume Rendering/Value range` | 值域窗口（设置可见密度范围） |
| `Volume Rendering/Settings` | 全局设置窗口（降采样提示、启用 SimpleITK、默认梯度类型） |

另有 **Assets 右键菜单** `Assets/Volume Rendering/Import dataset/...`（导入为资产）。

## 2. 体对象 Inspector（`VolumeRenderedObjectCustomInspector`）

选中体对象后在 Inspector 可配置：

- **Render mode**：DVR / MIP / Isosurface；
- **Visible value range**：可见密度值域（Isosurface 模式下作为阈值，另有 Gradient visibility threshold）；
- **Transfer function**：选择 1D/2D 类型、“Edit transfer function” 打开编辑窗口；
- **Lighting**：启用光照、梯度类型、光源、梯度光照阈值、启用阴影体（挂载 `ShadowVolumeManager`）；
- **PET/overlay volume**：加载次级体数据（NRRD/NIFTI）做叠加；
- **Segmentation**：分割标签管理与渲染模式（OverlayColour/Isolate）；
- **其他**：缩放归一化等（通过 Inspector 按钮）。

## 3. 脚本化 API 速查

### 导入
```csharp
// 工厂方式
IImageFileImporter imp = ImporterFactory.CreateImageFileImporter(ImageFileFormat.NIFTI);
VolumeDataset ds = await imp.ImportAsync(path);

// RAW 直接构造
RawDatasetImporter raw = new RawDatasetImporter(path, x, y, z, fmt, endian, skip);
VolumeDataset ds = raw.Import();
```

### 生成体对象
```csharp
VolumeRenderedObject obj = VolumeObjectFactory.CreateObject(dataset);        // 同步
VolumeRenderedObject obj = await VolumeObjectFactory.CreateObjectAsync(dataset); // 异步
```

### 体对象常用方法（`VolumeRenderedObject`）
- `SetRenderModeAsync(RenderMode, IProgressHandler)` / `GetRenderMode()`
- `SetTransferFunctionModeAsync(TFRenderMode, ...)` / `GetTransferFunctionMode()`
- `SetLightingEnabledAsync(bool, ...)` / `GetLightingEnabled()`
- `SetGradientTypeAsync(GradientType, ...)` / `SetLightSource(LightSource)`
- `SetVisibilityWindow(Vector2)` / `GetVisibilityWindow()`
- `SetOverlayType(OverlayType)` / `SetSecondaryTransferFunction(...)`
- `SetSegmentationLabels(...)` / `GetSegmentationLabels()`
- `CreateSlicingPlane()`：运行时创建切片平面
- `GetCrossSectionManager()`：获取切面管理器

### 渲染查询
```csharp
VolumeRaycaster raycaster = new VolumeRaycaster();
if (raycaster.RaycastScene(ray, out RaycastHit hit))
{
    // hit.point / hit.volumeObject / hit.distance
}
```

### 进度
```csharp
using (ProgressHandler progress = new ProgressHandler(editorProgressView, "Import"))
{
    progress.StartStage(0.7f, "Loading");
    // ... await 导入 ...
    progress.EndStage();
}
```

## 4. 运行时 GUI（IMGUI）

`Runtime/GUI/` 提供可在运行时（Play 模式）使用的界面：

- `RuntimeGUI` / `RuntimeFileBrowser`：运行时文件选择；
- `RuntimeTransferFunctionEditor`：运行时编辑传输函数；
- `DistanceMeasureTool`：场景中测量距离（基于 `VolumeRaycaster`）；
- `EditSliceGUI` / `EditVolumeGUI`：运行时移动切片/体对象；
- `ColourPickerPopup` / `ColourPicker`：颜色选择。

这些组件一般挂在示例场景的 UI 上（参考 `SampleProject~`）。

## 5. 脚本化导入器（Asset Pipeline）

- `RawScriptedImporter`：把 `.raw` 资产直接转为 `VolumeDataset` 资产，可在 Inspector 修改参数后 Apply；
- `ImageFileScriptedImporter`：把 NRRD/NIFTI/VASP 资产转为 `VolumeDataset`；
- `TransferFunctionScriptedImporter`：把传输函数资产导入。
- 拖入 `Assets` 即自动触发（`DragDropHandler`）。
