# 08 - 示例工程与数据

## 1. SampleProject~（示例 Unity 工程）

`SampleProject~/` 是一个完整的 Unity 工程，用于快速体验与开发调试：

- Unity 版本：**6000.0.25f1**
- 包引用：`Packages/manifest.json` 中 `com.mlavik1.unityvolumerendering` 通过 `"file:../../"` 指向包根目录，
  即**本地文件引用**方式（修改包内代码即时生效，适合开发）。
- 注意：仓库 README 提到 `DevProject~/` 用于开发，但当前仓库中的实际目录名为 `SampleProject~/`。

### 场景与脚本

| 文件 | 说明 |
| --- | --- |
| `Assets/Scenes/TestScene.unity` | 示例场景 |
| `Assets/Scripts/CameraController.cs` | 第一人称/自由摄像机控制器（WASD+QE 移动、鼠标滚轮缩放、Shift 加速、平滑插值） |

## 2. SampleData（示例数据）

`SampleProject~/SampleData/` 包含两个数据集：

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `VisMale.raw` | 8 MB | 可见人体计划（Visible Human Project）CT 数据集，256×256×128 左右 |
| `VisMale.raw.ini` | 50 B | 该 RAW 数据的导入参数（维度/格式），自动填充导入窗口 |
| `VisMale-license.txt` | 2.2 KB | 数据使用许可（NLM，未命名许可） |
| `PARCHG.0019_0020.0311.vasp` | 6.8 MB | VASP 电荷密度数据集 |
| `PARCHG.0019_0020.0311-license.txt` | 182 B | 许可文件 |

## 3. 包注册的 Samples（UPM）

`package.json` 中注册了两个可导入示例：

1. **Basic Demo**：场景 + 摄像机控制器 + 运行时 GUI（路径 `SampleProject~`）。
2. **Sample Data**：测试数据集（路径 `SampleProject~/SampleData`）。

安装包后在 Package Manager 的 Samples 选项卡可一键导入。

## 4. 快速体验步骤

1. 用 Unity Hub 打开 `SampleProject~`（6000.0.25f1）。
2. 打开 `Assets/Scenes/TestScene.unity`。
3. 菜单 `Volume Rendering` → `Load dataset` → `Load raw dataset`，选择 `VisMale.raw`。
4. 导入窗口会自动读取 `VisMale.raw.ini` 的默认参数，点击 import。
5. 场景中出现体对象，用 `CameraController` 环绕观察；在 Inspector 切换渲染模式/光照/传输函数。
