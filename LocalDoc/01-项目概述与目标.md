# 01 - 项目概述与目标

## 1. 项目是什么

UnityVolumeRendering 是一个开源的 **Unity 体数据渲染（Volume Rendering）插件**，
以 Unity Package Manager（UPM）包的形式发布（`com.mlavik1.easyvolumerenderer`）。

它主要面向**医学影像可视化**（CT / MRI / PET 等 DICOM 数据）以及**科学计算可视化**
（NIFTI、NRRD、VASP/PARCHG 电荷密度、RAW 体数据）场景，让开发者无需编写底层渲染代码，
就能在 Unity 中导入并交互式查看三维体数据。

## 2. 项目目标 / 解决的问题

1. **数据导入**：把各种体数据格式（DICOM、NIFTI、NRRD、VASP、RAW、图像序列）转换为
   Unity 可用的 `VolumeDataset` 资产。
2. **实时渲染**：在 Unity 中通过 GPU 光线步进（raymarching）实时渲染体数据，
   提供多种渲染模式与视觉效果。
3. **交互式分析**：提供切面（cross section）、切片（slice）、裁剪、测量、值查询等交互工具，
   方便医学/科研人员观察数据内部结构。
4. **易用性**：提供编辑器菜单、拖拽导入、运行时 IMGUI 界面与简洁的 C# 脚本 API。
5. **管线兼容**：同时支持 Unity Built-in、URP、HDRP 三种渲染管线。
6. **VR/AR 友好**：支持异步导入与立体渲染（stereo rendering），可运行于 VR。

## 3. 主要特性总览

| 类别 | 特性 |
| --- | --- |
| 渲染模式 | 直接体渲染 DVR、最大强度投影 MIP、等值面渲染 Isosurface |
| 传输函数 | 1D 传输函数（密度→颜色/不透明度）、2D 传输函数（密度+梯度幅值→颜色/不透明度） |
| 光照 | 基于梯度的 Phong 光照、可切换光源（主方向光 / 摄像机方向） |
| 阴影 | 阴影体（Shadow Volume，Compute Shader 计算、分块异步更新） |
| 采样 | 三线性 / 三三次（cubic）插值、噪声抖动、早期光线终止、采样率倍率 |
| 交互工具 | 切面平面、盒式/球式裁剪（inclusive/exclusive）、切片渲染器、距离测量、值查询 |
| 分割 | TotalSegmentator 标签自动识别、分割标签着色、Overlay/Isolate 渲染、PET 叠加 |
| 多体绘制 | 次级体数据叠加（PET/overlay）、多体隔离/叠加着色器变体 |
| 导入格式 | RAW、DICOM、NRRD、NIFTI、VASP/PARCHG、图像序列（JPG/PNG/TIFF） |
| 数据查询 | 体积光线投射（CPU 端 `VolumeRaycaster`） |
| 异步 | 异步导入、异步纹理生成、进度条反馈 |
| 脚本 API | `ImporterFactory`、`VolumeObjectFactory`、`VolumeRenderedObject` 等 |
| 运行时 GUI | IMGUI 运行时界面：文件浏览器、传输函数编辑、切片编辑、测量工具 |
