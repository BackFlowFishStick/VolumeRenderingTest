# 11 - 功能清单

> 按模块汇总 **Easy Volume Renderer**（`com.mlavik1.easyvolumerenderer` v1.8.0）提供的全部能力，
> 标注关键 API / 入口，并交叉引用详细文档。各项结论均经源码核实。
>
> 详细展开：导入见 [04](04-数据导入说明.md)，渲染见 [03](03-核心功能详解.md)，
> 编辑器/脚本 API 见 [07](07-编辑器工具与脚本接口.md)，管线适配见 [06](06-渲染管线与着色器.md)。

## 1. 数据导入

| 功能 | 说明 | 关键 API / 入口 |
| --- | --- | --- |
| DICOM 序列 | 内置 openDICOM 后端（全平台）；可选 SimpleITK 后端（支持 JPEG2000 压缩）。目录递归枚举、按 Series UID 自动拆分多序列、按切片位置排序、slope/intercept 转 HU、可选 HU clamp | `ImporterFactory.CreateImageSequenceImporter(ImageSequenceFormat.DICOM)` → `LoadSeriesAsync` → `ImportSeriesAsync` |
| NRRD (.nrrd) | **必须启用 SimpleITK** 后端，无内置回退 | `CreateImageFileImporter(ImageFileFormat.NRRD)` → `ImportAsync` |
| NIFTI (.nii / .nii.gz) | 内置 Nifti.NET 后端，或 SimpleITK | `CreateImageFileImporter(ImageFileFormat.NIFTI)` |
| RAW (.raw/.dat/.vol) | Int8~Uint32、大小端、bytesToSkip；同名 `.ini` 自动填参 | `RawDatasetImporter`（同步） |
| VASP/PARCHG (.vasp) | 材料科学电荷密度数据 | `CreateImageFileImporter(ImageFileFormat.VASP)` |
| 图像序列 | .jpg/.png（SimpleITK 下含 .tiff），每张图一个切片 | `CreateImageSequenceImporter(ImageSequenceFormat.ImageSequence)` |
| 异步导入 + 进度 | 全部导入器有 Async 版本 | `Task` 返回值 + `IProgressHandler` / `ProgressHandler` |
| 运行时导入 | 导入器全在 Runtime 程序集，Play 模式 / 打包后可用 | `RuntimeFileBrowser.ShowOpenFileDialog / ShowOpenDirectoryDialog` |
| 编辑器导入工作流 | 菜单、Assets 右键导入为 .asset、拖拽导入、ScriptedImporter | `Volume Rendering/Load dataset/...`（见 07） |
| 导入设置 | 降采样、归一化缩放（保持真实米制尺寸）、HU clamp、梯度类型 | `Volume Rendering/Settings`（PlayerPrefs 持久化） |
| SimpleITK 集成 | 一键启用，自动下载二进制并定义 `UVR_USE_SIMPLEITK` 宏；**每工程独立启用** | `Volume Rendering/Settings → Enable SimpleITK` |

统一数据模型：所有格式导入后均产出 `VolumeDataset`（ScriptableObject：维度、米制 scale、rotation、数据数组），
按需生成 Texture3D（RHalf/RFloat 按平台支持自动选择）、梯度纹理、min/max 查询、`DownScaleData`。

## 2. 体渲染核心

| 功能 | 说明 | 关键 API / 入口 |
| --- | --- | --- |
| 三种渲染模式 | DVR（直接体渲染）、MIP（最大强度投影）、Isosurface（等值面），运行时可切换。注：MIP 枚举名源码即拼写为 `MaximumIntensityProjectipon` | `VolumeRenderedObject.SetRenderModeAsync(RenderMode)` |
| GPU Raymarching | 早期光线终止（可关）、采样率倍率、cubic 插值；DVR/MIP 512 步、Isosurface 1024 步（`MAX_NUM_STEPS`） | `SetSamplingRateMultiplier`、`SetRayTerminationEnabled`、`SetCubicInterpolationEnabled` |
| 1D 传递函数 | 密度→颜色/不透明度控制点，纹理宽 1024 | `TransferFunction` + `SetTransferFunction(Async)`；`TransferFunctionDatabase` 创建/加载/保存 |
| 2D 传递函数 | 密度+梯度幅值二维映射（官方标记 WIP） | `TransferFunction2D`、`TFRenderMode.TF2D` |
| 可见性窗口 | 按值域过滤显示，同时决定等值面阈值（shader `_MinVal/_MaxVal`） | `SetVisibilityWindow(min, max)` |
| 光照 | 基于梯度的 Phong 光照，梯度算法 4 选 1（CentralDifference / Smoothed / Sobel / SmoothedSobel） | `SetLightingEnabled(Async)`、`SetGradientType(Async)`、`SetLightSource` |
| 阴影体 | Compute Shader 从光源方向计算 3D 阴影纹理（开销大，按需开） | `ShadowVolumeManager` |
| 多体渲染 | 多个 `VolumeRenderedObject` 共存，深度写入处理相交 | `VolumeObjectFactory.CreateObject(Async)` |
| 分割叠加 | 叠加第二数据集（如分割标注），标签映射（TotalSegmentator 预设）、结构着色/隔离 | `AddSegmentation`、`SetOverlayDataset`、`SetSegmentationLabels`、`OverlayType` |
| VR 立体渲染 | 单通道立体着色器（`UNITY_VERTEX_OUTPUT_STEREO`） | 无需额外配置 |

## 3. 切面与裁剪

| 功能 | 说明 | 关键 API / 入口 |
| --- | --- | --- |
| 切面平面 | 任意平面上重采样体数据显示 2D 断层截面；组件每帧推送矩阵，拖动 Transform 实时跟随；颜色走当前传递函数 | `VolumeRenderedObject.CreateSlicingPlane()` → `SlicingPlane` |
| 平面裁剪 | 沿平面挖除一侧体数据 | `VolumeObjectFactory.SpawnCrossSectionPlane` |
| 盒 / 球裁剪 | 盒内、球内挖空（最多 8 个裁剪体同时作用） | `SpawnCutoutBox`、`SpawnCutoutSphere`、`CrossSectionManager` |
| 切片编辑工具 | 编辑器 `Volume Rendering → Slice renderer` 窗口；运行时 `EditSliceGUI` | 见 07 |

## 4. 交互工具

| 功能 | 说明 | 关键 API / 入口 |
| --- | --- | --- |
| 射线拾取 | CPU 射线与体数据求交 | `VolumeRaycaster.RaycastScene(ray, out hit)` |
| 距离测量 | 运行时两点测距（基于射线拾取） | `DistanceMeasureTool.ShowWindow()` |
| 运行时 GUI 套件 | 导入对话框、体编辑面板、切片编辑、传递函数编辑器、颜色选择器 | `RuntimeGUI`、`EditVolumeGUI`、`EditSliceGUI`、`RuntimeTransferFunctionEditor` |

## 5. 平台与渲染管线

| 维度 | 支持情况 |
| --- | --- |
| 渲染管线 | **Built-in / URP / HDRP** 全支持；`RenderPipelineHelper` 运行时类型检测（带缓存），`ShaderFactory` 按管线返回对应着色器；核心 raymarching 逻辑三管线共用（`BackwardsCompatibility.hlsl` 矩阵宏）。**自定义 SRP（Unknown）不支持** |
| 性能 | raymarching 核心开销与管线基本无关；主导因素是包内参数（步数、采样率、early ray termination、阴影体、cubic、梯度算法），优化建议见 [10](10-快速上手指南.md) 第 5 节 |
| 桌面平台 | Windows / Linux / macOS，编辑器 + 独立构建 |
| WebGL | 可用但内存受限：需启用 `ALLOW_MEMORY_GROWTH`；无法访问本地文件系统，需预导入或 UnityWebRequest 下载数据 |
| SimpleITK | 仅桌面平台（Windows/Linux/macOS），编辑器 + standalone |
| Unity 版本 | package.json 声明最低 **2022.3**；README 推荐 Unity 6；官方 CI 同时用 2022.3.22f1 与 6000.0 打包（见 [09](09-依赖许可与构建发布.md)） |

## 6. 明确不支持的边界

- **.mrb**（3D Slicer Medical Reality Bundle）：无任何代码路径，需自行解包取内部 NRRD/NIfTI 再导入
- **.vti / .vtk**：无导入器
- **JPEG 压缩 DICOM**：内置 openDICOM 后端不支持，需启用 SimpleITK 后端
- **自定义渲染管线**：无对应着色器
- **2D 传递函数**：官方标记 WIP，功能可用但未稳定
