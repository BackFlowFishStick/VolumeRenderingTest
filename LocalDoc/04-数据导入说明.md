# 04 - 数据导入说明

## 1. 支持的格式一览

| 格式 | 扩展名 | 导入器 | 备注 |
| --- | --- | --- | --- |
| RAW 原始二进制 | `.raw` / `.dat` / `.vol` / `.ini` | `RawDatasetImporter` | 可带文件头（bytesToSkip）；支持 Int8/Uint8/Int16/Uint16/Int32/Uint32、大小端 |
| DICOM | `.dicom` / `.dcm` | `DICOMImporter`（OpenDICOM，全平台）或 `SimpleITKDICOMImporter`（推荐） | 文件夹中多张切片沿 Z 轴构成 3D 数据集；支持多 series |
| NIFTI | `.nii` / `.nii.gz` | `NiftiImporter`（Nifti.NET）或 SimpleITK 版本 | 推荐启用 SimpleITK |
| NRRD | `.nrrd` | `SimpleITKImageFileImporter`（**必须启用 SimpleITK**） | 无内建回退实现 |
| VASP/PARCHG | `.vasp` | `ParDatasetImporter` | 电荷密度数据 |
| 图像序列 | `.jpg` / `.jpeg` / `.png`（SimpleITK 下支持 `.tiff`） | `ImageSequenceImporter` / `SimpleITKImageSequenceImporter` | 每张图一个切片 |

格式自动识别：`DatasetImporterUtility.GetDatasetType(filePath)` 依据扩展名判断。

## 2. 导入方式（编辑器）

1. **菜单栏导入**：`Volume Rendering` → `Load dataset` → 选择具体格式。
   - RAW 会弹出导入参数窗口（X/Y/Z 维度、跳过字节数、数据格式、端序）。
   - 若与数据同名存在 `.ini` 文件（如 `VisMale.raw.ini`），会自动填充默认参数。
2. **拖拽导入**：把 RAW/NRRD/NIFTI/PARCHG 文件拖入 `Assets` 目录，生成 `VolumeDataset` 资产
   （通过 `Editor/ScriptedImporters` 的 `RawScriptedImporter` / `ImageFileScriptedImporter`）。
   - RAW 资产可在 Inspector 中修改参数后点 “Apply”。
3. **右键导入**：在 `Assets` 右键 → `Volume Rendering` → `Import dataset`（支持全部格式）。
4. **导入为资产 vs 导入到场景**：菜单导入默认生成场景对象；右键导入默认生成 `.asset` 资产。
   - 大体积数据建议以资产形式导入，避免场景文件过大。

导入流程均由异步实现（`ImportAsync`），并带 `ProgressHandler` 进度反馈；
编辑器会自动提示是否**降采样**（数据过大无法放入 3D 纹理时）。

## 3. SimpleITK 集成

- SimpleITK 是可选的原生库，用于：JPEG2000 压缩 DICOM、NRRD、更好的 NIFTI/DICOM 支持、
  TIFF 图像序列。
- 默认**禁用**（二进制较大）。在 `Volume Rendering` → `Settings` 中点击 “Enable SimpleITK”
  会自动下载对应平台二进制并定义 `UVR_USE_SIMPLEITK` 编译宏。
- `ImporterFactory` 在启用后自动返回 SimpleITK 实现。
- 支持平台：Windows / Linux / MacOS；原生库要求构建平台与目标平台一致。

## 4. 脚本化导入 API

统一入口 `ImporterFactory`（`Runtime/Importing/ImporterFactory.cs`）：

```csharp
// 单文件格式：NRRD / NIFTI / VASP
IImageFileImporter importer = ImporterFactory.CreateImageFileImporter(ImageFileFormat.NRRD);
VolumeDataset dataset = await importer.ImportAsync(file);

// 序列格式：DICOM / 图像序列
IImageSequenceImporter seqImporter = ImporterFactory.CreateImageSequenceImporter(ImageSequenceFormat.DICOM);
IEnumerable<IImageSequenceSeries> seriesList = await seqImporter.LoadSeriesAsync(filePaths);
VolumeDataset dataset = await seqImporter.ImportSeriesAsync(seriesList.First());
```

RAW 直接构造：

```csharp
RawDatasetImporter importer = new RawDatasetImporter(filePath, dimX, dimY, dimZ,
    DataContentFormat.Uint16, Endianness.LittleEndian, bytesToSkip);
VolumeDataset dataset = importer.Import();
```

导入后生成场景对象：

```csharp
VolumeRenderedObject obj = await VolumeObjectFactory.CreateObjectAsync(dataset);
```

> 所有导入器接口见 `Runtime/Importing/ImageFileImporter/Interface/IImageFileImporter.cs`
> 与 `Runtime/Importing/ImageSequenceImporter/Interface/IImageSequenceImporter.cs`。

## 5. 数据格式细节

- **VolumeDataset**（`Runtime/VolumeData/VolumeDataset.cs`）：
  - `data`：展平的 float 三维密度数组；
  - `dimX/dimY/dimZ`：三个维度大小；
  - `scale`（Vector3）与 `rotation`（Quaternion）：真实物理缩放/旋转（DICOM/NRRD 坐标系转换后，米制）；
  - 提供 `GetDataTexture()` / `GetGradientTexture()`（同步/异步），生成 `Texture3D`。
- **.ini 文件**（`DatasetIniReader`）：`dataset.raw` 旁放 `dataset.raw.ini` 记录维度、格式、端序等。
- **DICOM 字典**：`Runtime/Resources/dicom-elements-2007.dic.bytes`、`dicom-uids-2007.dic.bytes`
  供 OpenDICOM 解析使用。
